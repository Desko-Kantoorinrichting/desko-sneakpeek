# Desko sneak peek

De statische Desko-teaserpagina met aftelklok tot 28 september 2026, 11.00 uur Amsterdamse tijd.

## Hosting

De bestanden in de hoofdmap kunnen rechtstreeks via GitHub Pages worden gepubliceerd.

## Aanmeldingen

Het formulier verstuurt naam, e-mail en toestemming via FormSubmit naar marketing@desko.nl.
De eerste aanmelding triggert een activatie-e-mail; iemand met toegang tot die mailbox moet die bevestigen. Controleer daarna met een tweede testaanmelding of deze in de inbox komt. Controleer ook de spamfolder.

Bezoekers krijgen geen automatische e-mail. Desko gebruikt de ontvangen adressen voor één persoonlijke update.

## Domein

De eerdere DNS-records voor ChatGPT Sites zijn niet geschikt voor deze GitHub Pages-versie.
Stel het eigen subdomein eerst in via de Pages-instellingen en gebruik daarna de bijbehorende GitHub DNS-instructies.
